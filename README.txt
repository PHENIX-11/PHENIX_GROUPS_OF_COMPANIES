PHENIX GROUP'S OF COMPANIES — WEBSITE PACKAGE

Contents
- index.html: complete website with the official emerald-and-gold PHENIX logo in the header.
- assets/phenix-official-logo.webp: optimized square official group logo.
- assets/phenix-favicon.png and assets/favicon.ico: favicon files made from the same uploaded logo.
- assets/phenix-founder-suman.jpg: founder portrait.
- robots.txt and sitemap.xml: basic crawler discovery files.

Deployment
Upload the contents of this folder to the website's public web root. Keep the assets folder beside index.html.
This package has not been uploaded to the live website. Google controls whether and when it indexes a page.

Testing notes
- Inline JavaScript syntax and JSON-LD syntax were checked.
- Automated browser smoke tests checked navigation, the Apps page and filtering, PHENIX AI responses, and the guided tutorial's page transitions.
- External social embeds or remote resources may still be blocked by the browser, platform, or network. The website does not claim that PHENIX AI is connected to a live cloud AI service; it uses a local knowledge base.
